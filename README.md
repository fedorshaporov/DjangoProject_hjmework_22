## Skystore
Skystore - это веб-приложение интернет-магазина, разработанное с использованием Django. Приложение предоставляет пользователям возможность просматривать каталог товаров и связываться с администратором через форму обратной связи.
## Установка
* Клонируйте репозиторий:
'''
git clone git@github.com:fedorshaporov/DjangoProject_hjmework_22.git cd DjangoProject_hjmework_22
'''
* Создайте виртуальное окружение:
'''
python -m venv venv
'''
## Запуск приложения
* Запустите сервер:
'''
python manage.py runserver
'''
* Перейдите по следующему адресу в вашем браузере:
'''
http://127.0.0.1:8000/
'''
## Структура проекта
* catalog/: Приложение для отображения каталога товаров и управления страницами.
* migrations/: Миграции для базы данных.
* views.py: Контроллеры для обработки запросов.
* urls.py: Маршрутизация URL-адресов.
* templates/catalog/: HTML-шаблоны приложения, включая страницы:
* home.html: Главная страница.
* contacts.html: Страница с контактной информацией и форма обратной связи.
* contact_success.html: Страница, отображаемая после успешной отправки формы.
## Функциональность
* Просмотр главной страницы с каталогом товаров.
* Страница контактов с формой обратной связи.
* Возможность отправить сообщение с именем, телефоном и текстом сообщения.
* Сообщение об успешной отправке формы.
## Используемые технологии
* Python
* Django
* Bootstrap
